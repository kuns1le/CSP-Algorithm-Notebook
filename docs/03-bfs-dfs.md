# BFS / DFS

完整可复制实现见 [algorithms.hpp](../templates/algorithms.hpp)：bfs、dfs_order。

| 问题结构 | 常用方法 | 前提 |
| --- | --- | --- |
| 无权图、等权图的最少步数 | BFS | 每步代价相同，状态与转移定义正确 |
| 连通块、可达性 | BFS 或 DFS | 无向图连通块；有向图要区分弱连通、强连通和可达 |
| 树的子树统计 | DFS | 需要明确父节点和后序处理 |
| 枚举排列、组合、所有路径 | DFS + 回溯 | 状态规模允许，回退时撤销本层选择 |

## BFS

队列按层推进，第一次到达一个状态时得到最少边数。距离设为 -1 表示未访问，起点设 0。**入队时标记**，防止同一状态反复入队。

~~~cpp
auto dist = csp::bfs(g, start);
if (dist[target] == -1) {
    // 不可达。
}
~~~

邻接表下时间 O(V+E)，额外空间 O(V)。四方向网格把 V 视为格子数，转移数为常数倍 V。先检查边界、障碍和访问状态，再入队。

不同权重不能直接套此最短路模板；0/1 权可学 0-1 BFS，一般非负权用 Dijkstra。

## 网格与传送门：先定义一步

网格连通块见 [grid-components.cpp](../examples/grid-components.cpp)，传送门最短路见 [grid-portals.cpp](../examples/grid-portals.cpp)；函数为 grid_components、grid_portal_distance。

- 连通块模板：字符 1 是陆地、0 是水，四方向相连。每遇到一个未访问陆地，答案加一，再用显式栈标记整个块。不同启动点对应互不相交的块；每格最多入栈一次，时间和额外空间均 O(RC)。空网格、单格、对角接触、全水、多个块均要检查。
- 传送门模板：非空矩形网格，# 为墙、. 为空地，S/T 为唯一的起终点。其余大写字母每种恰好两个。走入传送门并到配对出口合计一步，到达出口不立即再次传送。
- 状态是“本次移动结束后所在格子”。从四邻格进入传送门时，先映射到出口，再检查并标记出口距离；不要把进入点误当本次移动的落点。

每条这样的转移都恰好花一步，普通 BFS 的分层性质成立。扫描配对位置后，每个格子最多入队一次，时间、额外空间均 O(RC)，无需显式建立所有边。

传送门示例输入，输出 5：

~~~text
3 5
S.A##
#####
A..T#
~~~

若题目允许独立的零代价传送边，应改用 0-1 BFS；传送是否强制、是否耗时、同字母是否超过两个，均需重新建模。若还带钥匙或使用次数，访问状态可能要包含额外信息，不能只按坐标去重。

## DFS 与连通块

dfs_order 使用显式栈，适合可达性，避免深递归造成栈溢出。它的返回顺序不是递归 DFS 的退出顺序，不能直接据此计算后序动态规划。

无向图连通块应维护**全图共享**的 visited，对每个未访问顶点启动一次遍历。不要对每个顶点重新创建 visited 后遍历整个图，否则会重复工作。

树上递归的最小结构（需 vector、声明好的 g、C++17）：

~~~cpp
auto dfs = [&](auto&& self, int u, int parent) -> void {
    for (int v : g[u]) {
        if (v == parent) continue;
        self(self, v, u);
        // 此时 v 的子树已处理，可合并到 u。
    }
};
dfs(dfs, root, -1);
~~~

仅跳过 parent 适用于树等相应结构，普通有环图必须另加 visited。深链树要改为显式栈和逆序合并。

## 回溯和全局 visited 的区别

枚举所有可行路径时，通常是“选择—递归—撤销”。判断一次可达性时通常无需撤销全局 visited。是否撤销取决于状态含义，不能机械套用。

排列枚举最坏 O(n!·n)，子集枚举最坏 O(2^n·n)，这里包含输出或复制每个结果的成本。剪枝可以减少实际搜索量，不能随意降低最坏复杂度结论。

## 最少测试

起点等于终点、不可达、孤立点、环、多个连通块；网格补充 1×1、贴边路线、全障碍。
