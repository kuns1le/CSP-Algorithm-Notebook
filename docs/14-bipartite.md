# 二分图专题：染色、最大匹配与建模

以文字原理和关键 C++17 片段为主，不依赖自定义类。顶点编号从 1 开始，矩阵坐标从 0 开始。

## 1. 二分图与匹配不是同一个问题

二分图是可以将所有顶点划分为两个集合，使每条边都连接不同集合的图。无向图是二分图，当且仅当它不含奇数长度的环（自环也属于奇环）。

匹配是一些互不共享端点的边；最大匹配是使所选边数最大的匹配。如果左部有 n 个点，右部有 m 个点，最大匹配数不超过 min(n,m)。两侧相同编号是不同顶点。重边是连接同一对端点的多条边，重复输入不改变最大匹配数。

| 判断信号 | 算法 |
| --- | --- |
| 相邻顶点必须处于不同状态、判断能否二染色 | BFS / DFS 染色 |
| 两类对象一对一配对，求最多配成多少对 | DFS 增广路（竞赛中常称匈牙利算法） |
| 一次操作可以同时修正一对不同类型的错误 | 尝试转化成最大匹配，证明每次匹配的节省量及最优性 |

注意：这里的 DFS 增广路算法求的是**无权最大匹配**；带权匹配是另一类问题，不能简单按价值调用这个模板。

## 2. 二分图染色：每条边两端必须不同

**适配题型。** 河蟹封锁道路：每条边至少有一个端点被选择（才能封锁），同时不能两个都选（会冲突）。因此每条边恰好一个端点被选择。令颜色0和颜色1代表两个集合；若存在同色相邻点，说明无解。

**为什么分连通块取最小值？** 一个连通块中，一旦固定起点颜色，其余点沿路径的颜色就被确定。若染色合法，所有合法方案只有整块的两种颜色互换。因此选择较小的颜色集合即可。不同连通块之间没有边，可以各自选择颜色，答案为各块的 min(cnt[0],cnt[1]) 之和，而不是最后统一比较全图的两种颜色数。孤立点贡献0。

~~~cpp
// g 为无向邻接表 vector<vector<int>>，边双向存储
vector<int> color(n+1,-1);
int ans=0;
for(int i=1;i<=n;i++){
    if(color[i]!=-1) continue; // 已处理的整个连通块不会重复 BFS
    queue<int> q;
    color[i]=0;
    q.push(i);
    int cnt[2]={1,0}; // 起点已经计入
    while(!q.empty()){
        int u=q.front(); q.pop();
        for(int v:g[u]){
            if(color[v]==-1){
                color[v]=1-color[u];
                cnt[color[v]]++;
                q.push(v);
            }else if(color[v]==color[u]){
                cout<<"Impossible";
                return 0; // 位于 main 中时直接结束
            }
        }
    }
    ans+=min(cnt[0],cnt[1]); // 每个连通块结束后累加
}
~~~

外层 for 只是寻找尚未染色的连通块，不是从每个点重跑 BFS。每个点入队一次，每条无向边检查两次，时间 O(n+m)，含存图空间 O(n+m)。不能只从顶点1开始（原图可能不连通）。在一般的最小顶点覆盖问题中，并没有“相邻点不能同时选”的限制，不能直接照搬本题的取较小颜色集合公式。

## 3. 最大匹配：DFS 寻找增广路

**适配题型。** 学生与岗位、左右顶点之间的最大一对一配对数。输入已明确左右部时无需再做二染色，只将左点连接到可匹配的右点。

**为什么不能直接贪心？** 左1可以匹配右1或右2，左2只能匹配右1。先让左1匹配右1后，左2并非一定失败：可以让左1改去右2，腾出右1给左2。

增广路从未匹配的左点出发，沿未匹配边和已匹配边交替走，最后到达空闲右点。将这条路上的边匹配状态反转，匹配数增加1。找不到增广路时匹配最大（Berge 定理）。依次加入左点，每次尝试一次增广，保持已处理左部的最大匹配；增加一个左点至多使最优匹配数增加1。

~~~cpp
// 全局变量；g[u] 是左点 u 的右侧邻居
vector<vector<int>> g;
vector<int> match;   // match[v] 是右点 v 匹配的左点，0 表示空闲
vector<bool> visited;// 本轮搜索是否尝试过右点 v

bool dfs(int u){
    for(int v:g[u]){
        if(visited[v]) continue;
        visited[v]=true;
        if(match[v]==0 || dfs(match[v])){
            match[v]=u;
            return true;
        }
    }
    return false;
}
~~~

bool 返回值告诉上一层“能否为当前左点找到位置”。若右点空闲，逻辑或短路，不调用 dfs(0)；否则递归尝试让原匹配者换位置。成功才修改 match[v] 并返回。visited 防止同一次递归反复尝试同一右点、进入无限递归；它不是是否已经匹配的标记。

~~~cpp
// 左部 n 点、右部 m 点、e 条边
g.resize(n+1);
match.assign(m+1,0);
visited.resize(m+1);
// 输入每条边 (u,v)，只需 g[u].push_back(v)
int ans=0;
for(int u=1;u<=n;u++){
    fill(visited.begin(),visited.end(),false); // 每轮清空整个右部标记
    if(dfs(u)) ans++;
}
~~~

match 必须跨轮保留，visited 只在外层开始一次新搜索时重置，递归内部不能清空。即使有重边也能正确匹配，visited 会跳过重复尝试。时间 O(n(e+m))（包含每轮清空 visited），空间 O(n+m+e)，另有递归栈 O(min(n,m)+1)。不要把左点编号直接当作右部 visited 的重置下标。

## 4. 网格建模：黑白马赛克相异度

两张 M×N 的 0/1 矩阵 A、B，单独翻转一个格子、交换上下左右相邻格子各花费1。设 cnt 为初始不相同的格子数。全部单独翻转的代价是 cnt。若相邻的两个错误格子分别需要 0→1 与 1→0，则一次交换能修正两个格子，比单独翻转节省1。最多找到 k 对互不重叠的这样的格子，答案为 cnt−k。

**为什么允许多步交换仍然不会得到更小代价？** 每个初始错误格子至少需要一次改变颜色。观察任意可行操作序列中，每个初始错误格子的首次颜色改变。一次操作至多对应两个这样的首次改变；若同时对应两个，它一定是交换两个相邻且初始颜色相反的错误格子。不同的这类操作不会共享首次改变的格子，因此构成合法匹配，次数不超过最大匹配 k。设这类操作有 t 次，其余操作至多对应一个首次改变，总代价至少 cnt−t≥cnt−k。直接交换最大匹配中的格子，再翻转未匹配的错误格子，恰好达到下界。

**建图：** 0→1 的错误格子作为左部；1→0 作为右部；仅相邻时连边。统一格子编号 id=r*N+c+1，避免与 match 的空闲标记0冲突。无需为两侧分别连续编号。

~~~cpp
g.assign(M*N+1,{});
match.assign(M*N+1,0);
visited.assign(M*N+1,false);
vector<int> left;
int cnt=0;
int dr[4]={-1,1,0,0}, dc[4]={0,0,-1,1};
for(int r=0;r<M;r++){
    for(int c=0;c<N;c++){
        if(A[r][c]!=B[r][c]) cnt++;
        if(A[r][c]!=0 || B[r][c]!=1) continue;
        int u=r*N+c+1;
        left.push_back(u);
        for(int d=0;d<4;d++){
            int nr=r+dr[d], nc=c+dc[d];
            if(nr<0||nr>=M||nc<0||nc>=N) continue;
            if(A[nr][nc]==1 && B[nr][nc]==0)
                g[u].push_back(nr*N+nc+1);
        }
    }
}
int k=0;
for(int u:left){
    fill(visited.begin(),visited.end(),false);
    if(dfs(u)) k++;
}
cout<<cnt-k<<'\n';
~~~

设 V=MN，网格边数 O(V)，最坏时间 O(V²)，空间 O(V)。检查完全相同、只有一种错误类型、1×1、相邻对、非相邻对、长方形的行列边界。此处记录算法和证明，不代表先前的在线 WA 已定位或已通过评测。
