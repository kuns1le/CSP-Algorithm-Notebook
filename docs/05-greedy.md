# 贪心：证明每一步选择安全

完整示例函数见 [algorithms.hpp](../templates/algorithms.hpp)：max_nonoverlap。

## 什么时候考虑

每一步做局部选择后，剩余问题仍具有可用结构，并且可以证明局部选择不会丢失最优解。常见证明方式是交换论证、领先性论证。排序只是实现手段，不是正确性证明。

## 例：最多选择多少个互不重叠区间

约定区间为 [l,r)，l<r；前一区间的终点等于后一区间的起点时允许同时选择。

策略：按结束时间升序排序，每次选起点 >= 上次终点的区间。

证明：取任意最优方案的第一个区间。将它换成所有候选中结束最早的区间，不会挤占后面区间的空间，区间数量不减少。对余下候选重复此论证。

~~~cpp
vector<pair<long long,long long>> intervals{{1,3},{2,4},{3,5}};
int answer = csp::max_nonoverlap(intervals); // 2
~~~

时间 O(n log n)，排序后扫描 O(n)。函数按值接收区间，会复制输入并需要 O(n) 的输入副本空间。

## 为什么不能照搬

- 改成最大总收益：结束最早的区间可能收益很低，通常要考虑带权区间 DP。
- 要求闭区间不能接触：相容条件可能要从 >= 改为 >。
- “总选当前最大的”“总选单位价值最高的”都需要证明。0/1 背包不能照搬可分割背包的单位价值策略。

## 找反例的方法

先构造 2～4 个候选，让最有吸引力的局部选择挡住两个总体更好的选择。把算法和暴力枚举在小规模随机数据上比较；有反例说明策略错误，没有反例仍不等于证明。
