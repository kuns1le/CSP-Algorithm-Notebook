# 易错点 / 错题

## 提交前检查

- [ ] 输入是单组、T 组、EOF 还是结束标记？每组状态是否重置？
- [ ] 题目编号是否已统一成 0-based？区间是闭区间还是 [l,r)？
- [ ] 空容器、n=1、重复值、全相等、负数是否处理？
- [ ] 总和、乘法、下标计算、距离累加是否可能溢出？
- [ ] 迭代器、end、数组右端点有没有越界？
- [ ] 二分是否有单调性？无解哨兵是否会被当成答案？
- [ ] BFS 是否入队时标记？普通图 DFS 是否防环？
- [ ] Dijkstra 是否有负边？不可达是否单独输出？
- [ ] 排序比较器是否严格？相等元素的处理是否符合题意？
- [ ] 输出大小写、精度、换行是否符合要求？是否删掉调试输出？

## 常见错误及最小反例

| 错误 | 反例 / 检查办法 |
| --- | --- |
| 把 1 当质数 | 输入 1 检查判素函数；原题未必允许 1，函数边界仍应明确 |
| 看到“最小”就二分 | 质数标记在 2,3,4,5 上为真、真、假、真，不单调 |
| 排序后忘记原下标 | 输出原位置时需携带 index |
| vector(n+1) 只读 n 个数，却全范围排序 | n=1、输入 5，会混入默认值 0；0-based 用 vector(n)，1-based 则只排序 [begin()+1,end()) |
| 比较 a[i+1] 却写 i<n | i=n-1 时越界；循环条件用 i+1<n |
| 全局 vector 按尚未读入的 n 初始化 | 全局 n 初值 0，vector(n+1) 长度为 1；读入 n 后 assign/resize 或再创建 |
| accumulate 初值写成 0 | 多个大 int 累加超过 int |
| ans 是 long long，但 a*b 先按 int 相乘 | a=10^9、b=3 已超 int；写 1LL*a*b，总和也要用足够宽的类型 |
| 用 unsigned 的 size()-1 | 空 vector 时会下溢 |
| 把 vector 的 reserve 当 resize | reserve 仅调整容量，不能据此访问新下标 |
| map 下标查询造成插入 | 统计容器大小在“查找”后意外增加 |
| unique 后忘记 erase | size 没有缩小 |
| BFS 出队才标记并重复入队 | 菱形图中同一顶点被多个父节点发现 |
| 递归 DFS 只跳过父节点就用于普通图 | 三角环仍会重复访问 |
| 贪心只测样例 | 构造一个局部最优挡住两个更优选择的小例子 |

上述代码模式按已有学习材料归纳，不表示已收到对应的在线错误提交。二分的开闭区间、可行端点和跳石头终点处理统一见 [二分边界](04-binary-search.md)，此处不重复模板。

## 数值计算与浮点精度

估算中间结果和总和：距离累加可能达到 n×最大坐标差。把结果变量声明为 long long，并不能修复此前已经发生的 int 乘法溢出。

整数除法会先截断：double ratio=a/b 仍可能丢失小数，应在运算前转换，如 1.0*a/b（b!=0）。浮点比较按题目误差要求选容差，输出用 fixed 和 setprecision；设置输出位数不会补回计算误差。不要在 sort 比较器里直接加入 eps 来判断大小，以免破坏严格弱序。分数背包的密度比较见 [贪心](05-greedy.md)。
