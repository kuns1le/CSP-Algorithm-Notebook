# 前缀和 / 差分

可复用的一维实现见 [algorithms.hpp](../templates/algorithms.hpp)：PrefixSum、Difference。

| 场景 | 工具 | 成本 |
| --- | --- | --- |
| 数组不变，多次问区间总和 | 前缀和 | 预处理 O(n)，每次 O(1) |
| 多次区间加，最后统一取值 | 差分 | 每次修改 O(1)，最终还原 O(n) |
| 修改和查询交错，要求每次马上回答 | 树状数组 / 线段树等 | 不能仅凭一次前缀和或最后还原的差分解决；后续补充 |

## 一维前缀和

约定 p[0]=0，p[i+1]=p[i]+a[i]，那么 [l,r) 的和是 p[r]-p[l]。

~~~cpp
vector<long long> a{2, -1, 4};
csp::PrefixSum p(a);
auto sum = p.sum(1,3); // -1+4=3
~~~

如果题目询问从 1 开始的闭区间 [L,R]，转换为模板的 [L-1,R)。总和必须能放进 long long。空区间返回 0。

## 一维差分

d[0]=a[0]，d[i]=a[i]-a[i-1]。给 [l,r) 加 v，只要 d[l]+=v、d[r]-=v，再对差分求前缀和还原。

~~~cpp
csp::Difference diff(vector<long long>{2,-1,4});
diff.add(0,2,3);
auto a = diff.values(); // {5,2,4}
~~~

模板预留 n+1 个差分位置，所以 r=n 时合法。这里是离线批量修改：频繁调用 values() 每次仍是 O(n)。

## 二维前缀和

设 a 的下标从 0 开始，p 多一行一列且初始为 0：

~~~cpp
p[i+1][j+1] = a[i][j] + p[i][j+1] + p[i+1][j] - p[i][j];
~~~

矩形 [x1,x2)×[y1,y2) 的和：

~~~cpp
long long sum = p[x2][y2] - p[x1][y2] - p[x2][y1] + p[x1][y1];
~~~

预处理 O(nm)，查询 O(1)，空间 O(nm)。检查行列顺序和 long long。

## 二维差分

给矩形 [x1,x2)×[y1,y2) 加 v：

~~~cpp
d[x1][y1] += v;
d[x2][y1] -= v;
d[x1][y2] -= v;
d[x2][y2] += v;
~~~

d 至少分配 (n+1)×(m+1)。以上更新针对差分数组；原矩阵非零时需先构建二维差分，或还原增量后再加原矩阵。还原使用二维前缀递推，不能只分别扫描一条边。

## 容易漏的测试

空区间、单元素、整段修改、负数、多个更新叠加、右端点刚好是 n；二维补充整行、整列和整个矩阵。
