# 动态规划（DP）速查

C++17。优先写清楚：**状态含义 → 当前决策 → 转移 → 初值 → 计算顺序**。求最大值用 `max`，最小代价用 `min`，方案数对互斥情况求和。

| 题目特征 | 典型状态 | 方法 |
| --- | --- | --- |
| 跳跃/移动最小代价 | `dp[i]`：到达 i 的最小代价 | 枚举上一步 |
| 选择受前一步类别限制 | `dp[i][c]`：第 i 步选 c 的最优值 | 分类转移 |
| 选物品且有限容量 | `dp[j]`：容量上限 j 的最大收益 | 0/1 背包 |
| 每种动作能重复 | `dp[h]`：完成目标 h 的最小费用 | 完全背包思想 |
| 子序列/序列构造方案数 | `dp[j]`：形成目标前 j 项的方案数 | 计数 DP |
| 大量区间查询同一计数序列 | `dp[i]` + `pre[i]` | 先预处理再 O(1) 查询 |

下述片段为核心模板，默认 `#include <bits/stdc++.h>`、`using namespace std;`，输入变量已准备好。

## 1. Frog 1 / Frog 2：最小代价

`dp[i]` = 到达第 i 块石头的最小代价（0 下标）。每次最多跳 K 格；Frog 1 取 K=2。

```cpp
const int INF=1e9;
vector<int> dp(n,INF);
dp[0]=0;
for(int i=1;i<n;i++)
    for(int d=1;d<=K && i-d>=0;d++)
        dp[i]=min(dp[i],dp[i-d]+abs(h[i]-h[i-d]));
// 答案 dp[n-1]
```

依赖更早的状态，因此正序计算；O(NK) 时间、O(N) 空间。

## 2. Vacation：连续两天活动不能相同

`dp[c]` = 处理到今天，且今天选活动 c 时的最大幸福值。当天的 `v[i][c]` 加上昨天另外两种活动的最大值。

```cpp
array<long long,3> dp={v[0][0],v[0][1],v[0][2]};
for(int i=1;i<n;i++){
    array<long long,3> next={
        v[i][0]+max(dp[1],dp[2]),
        v[i][1]+max(dp[0],dp[2]),
        v[i][2]+max(dp[0],dp[1])
    };
    dp=next;
}
// 答案 max({dp[0],dp[1],dp[2]})
```

只用上一天的状态：O(N) 时间、O(1) 辅助空间。

## 3. 0/1 背包：每件物品最多取一次

`dp[j]` = 背包容量**上限**为 j 时的最大价值；每件物品重量 `wi`、价值 `vi`。

```cpp
vector<long long> dp(W+1,0);
for(auto [wi,vi]:items)
    for(int j=W;j>=wi;j--)
        dp[j]=max(dp[j],dp[j-wi]+vi);
// 答案 dp[W]
```

**容量倒序**避免同一件物品重复使用。O(NW) 时间、O(W) 空间。二维版为 `dp[i][j]=max(dp[i-1][j],dp[i-1][j-wi]+vi)`（第二项仅在 `j>=wi` 时可用）。

## 4. 重复法术：完全背包的最小消耗变形

`dp[h]` = 击败生命值 h 的怪物最少魔法消耗；每种法术可重复，伤害超额也算击败。

```cpp
const int INF=1e9;
vector<int> dp(H+1,INF);
dp[0]=0;
for(int h=1;h<=H;h++)
    for(auto [damage,cost]:spells)
        dp[h]=min(dp[h],dp[max(0,h-damage)]+cost);
// 答案 dp[H]
```

O(HN) 时间、O(H) 空间；所有伤害须为正，因而依赖更小的 h。

## 5. 坏台阶：方案数

`dp[i]` = 不踩坏台阶到达第 i 级的走法数，每步上 1 或 2 级。 `broken[x]` 表示第 x 级是否损坏。

```cpp
const int MOD=1000000007;
vector<int> dp(n+1,0);
dp[0]=1;
for(int i=1;i<=n;i++){
    if(broken[i])continue;
    dp[i]=dp[i-1];
    if(i>=2)dp[i]=(dp[i]+dp[i-2])%MOD;
}
// 答案 dp[n]
```

空路径对应一种基础方案；O(N+M)（含坏台阶标记）时间、O(N) 空间。

## 6. chokudai：子序列计数（一维状态压缩）

`dp[j]` = 已扫描的字符串中，选出目标串前 j 个字符的方案数。

```cpp
string target="chokudai";
const int MOD=1000000007;
vector<int> dp(target.size()+1,0);
dp[0]=1;
for(char c:s)
    for(int j=(int)target.size();j>=1;j--)
        if(c==target[j-1])
            dp[j]=(dp[j]+dp[j-1])%MOD;
// 答案 dp[target.size()]
```

每个字符最多选一次，通用模板**倒序**更新。O(|S|×|target|) 时间、O(|target|) 空间。

## 7. 单调不降序列计数：前缀和优化转移

`dp[j]` = 已选前缀合法且**末尾恰为 j**的方案数。若当前位选 j，前一位可以是 0..j；还需满足 `a[i]<=j<=b[i]`。

```cpp
const int MOD=998244353, V=3000;
vector<int> dp(V+1,0);
dp[0]=1;
for(int i=0;i<n;i++){
    long long sum=0;
    for(int j=0;j<=V;j++){
        sum=(sum+dp[j])%MOD;  // 先读取上一轮的 dp[j]
        dp[j]=(a[i]<=j && j<=b[i]) ? (int)sum : 0;
    }
}
// 答案：将 dp[0..V] 相加后取模
```

原三重枚举经前缀和优化为 O(NV) 时间、O(V) DP 空间；**先累加旧值，再覆盖当前格**。

## 8. 数字金字塔：从底向上最大路径和

`a[i][j]` 原本存数值；更新后代表**从 (i,j) 到底层的最大路径和**。

```cpp
for(int i=r-2;i>=0;i--)
    for(int j=0;j<=i;j++)
        a[i][j]+=max(a[i+1][j],a[i+1][j+1]);
// 答案 a[0][0]
```

输入第 i 行长度为 i+1；O(r²) 时间、除输入外 O(1) 空间。

## 9. Boredom：相邻数值互斥的最大收益

`cnt[i]` = 数字 i 的个数；`dp[i]` = 只考虑数值不超过 i 的最大分数。

```cpp
vector<long long> dp(V+1,0);
dp[1]=cnt[1];
for(int i=2;i<=V;i++)
    dp[i]=max(dp[i-1],dp[i-2]+1LL*i*cnt[i]);
// 答案 dp[V]
```

不选 i 继承 `dp[i-1]`；选 i 需排除 i-1。O(N+V) 时间（含计数）、O(V) 空间。

## 10. Flowers：方案数 DP + 多组区间查询

`dp[i]` = 长度恰好 i 的合法花序列数：末尾加 1 朵红花，或加整组 k 朵白花。所有查询共用同一 k。

```cpp
const int MOD=1000000007, V=100000;
vector<int> dp(V+1,0),pre(V+1,0);
dp[0]=1;
for(int i=1;i<=V;i++){
    dp[i]=dp[i-1];
    if(i>=k)dp[i]=(dp[i]+dp[i-k])%MOD;
    pre[i]=(pre[i-1]+dp[i])%MOD;
}
// 查询闭区间 [l,r]
int ans=(pre[r]-pre[l-1]+MOD)%MOD;
```

`pre[i]` 是 **长度 1..i 的方案数前缀和**，与 `dp[i]` 含义不同。O(V+t) 时间、O(V) 空间。

## 一句话复习

- **状态是什么**比代码写几层循环重要；先写出“第 i 个、容量 j、末尾值 j”的准确中文含义。
- **选或不选 / 最后一步是什么**：max、min、方案数相加分别对应不同目标。
- **只依赖上一轮**才能压缩状态；0/1 背包与子序列计数通常倒序；单调序列计数先读旧 `dp[j]` 再覆盖。
- **多组查询同一 k**：共用一次 DP，预处理前缀和；取模减法用 `(x-y+MOD)%MOD`。
