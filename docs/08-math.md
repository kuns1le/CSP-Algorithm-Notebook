## 单个数判质数

n<2 时不是质数。如果 n 有非平凡因数，则一定有一个因数不超过 sqrt(n)。尝试 d<=n/d，可以避免 d*d 在整数类型中溢出。

试除时间 O(sqrt(n))，空间 O(1)。适合数值不大的单次或少量查询；大量查询考虑筛法，64 位大整数不要直接认为试除足够快。

寻找不小于 X 的最小质数，用从 X 向上枚举并判素；[完整例题](../problems/next-prime.md)。

## 多次查询：埃氏筛

~~~cpp
auto prime = csp::sieve(100000);
bool answer = prime[x]; // 要求 0 <= x <= 100000。
~~~

筛表覆盖 [0,n]，0 和 1 为 false。从 p*p 开始标记，因为更小的倍数已被更小质因子处理。时间 O(n log log n)，空间 O(n)；边界 n=0、n=1 也可用。

查询“下一个质数”时，筛表上界必须覆盖答案，不能只按输入最大值建到 100000 就断定足够。

## gcd / lcm

~~~cpp
long long g = std::gcd(a,b); // <numeric>，C++17。
// a,b 均为非负数，且结果可由 long long 表示。
long long l = (a == 0 || b == 0) ? 0 : a / g * b;
~~~

先除后乘只减少溢出机会，不保证结果一定不溢出。gcd(0,0)=0；计算 lcm 时避免除以零。std::gcd 的参数绝对值必须能在对应公共类型中表示，特别留意 LLONG_MIN。

## 取模和快速幂

正模数 m 下，把可能为负的 x 规整到 [0,m)：

~~~cpp
long long r = x % m;
if (r < 0) r += m; // 避免先做 x+m 导致溢出。
~~~

快速幂按二进制分解指数，每轮平方，时间 O(log exponent)。本模板限制 1<=mod<=1000000009、exponent>=0，以保证 long long 乘法安全；更大模数需要另换安全乘法实现。

不能把除法直接变成“取模后相除”。模逆元是否存在需要单独判断：a 与 m 互质才有逆元；使用费马小定理求逆还要求模数为质数且 a 不是它的倍数。

## 常见整数技巧

- 非负 a、正 b 的向上取整：a/b + (a%b!=0)，避免 a+b-1 溢出。
- 乘法提升类型：long long area=1LL*width*height；结果变量是 long long 不会自动修复前面 int 乘法溢出。
- 需要精确平方判断时先估计整数根，再用整数比较校正，注意乘法溢出。
- 位操作要检查移位数范围；不要把负数移位当作通用整数运算模板。
- x&(x-1) 可清掉最低位的 1；判断是否为 2 的幂还必须满足 x>0。

数学代码也要写清数值范围、符号范围和中间结果上界。
